ABISSES v56 — ATELIER PHOTOS MODULAIRE
======================================

Ce dossier contient uniquement les fichiers à copier dans le dépôt Abisses
déjà à jour en v55.

1. Fermer Abisses.
2. Copier tout le contenu de ce dossier dans le dossier local du dépôt
   SJZinknet/Abisses, en acceptant le remplacement des fichiers.
3. Ouvrir GitHub Desktop et vérifier l'onglet Changes.
4. Commit conseillé : v56 - Atelier Photos modulaire et carte agrandie
5. Push origin.

Pour tester le git pull automatique, lancer ensuite Abisses depuis UNE AUTRE
copie Git propre et non modifiée, avec lancer_gestion_bisses.bat sous Windows
ou lancer_gestion_bisses.py sous Ubuntu. Le terminal doit afficher :

    Recherche d'une mise à jour GitHub...

Une installation issue d'un fichier .deb ou .exe n'est pas un clone Git et
ne peut donc pas se mettre à jour par git pull.
